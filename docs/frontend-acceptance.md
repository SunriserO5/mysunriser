# 前端最小验收说明

## 1. 启动方式

### 启动后端

在项目根目录执行：

```bash
cd backend
./mvnw spring-boot:run
```

默认监听 `http://localhost:8080`。

### 启动前端开发服务器

在项目根目录执行：

```bash
cd frontend
npm run dev
```

默认访问 `http://localhost:5173`。

## 2. 联调验证路径

1. 首页：`/`
2. 博客列表：`/blog`
3. 文章详情：`/blog/:slug`
4. 关于页：`/about`
5. 登录页：`/login`
6. 管理员新建文章：`/admin/posts/new`
7. 管理员账号管理：`/admin/users`
8. 管理员文件管理：`/admin/files`
9. 管理员安全设置：`/admin/security`
10. 管理员页脚设置：`/admin/footer`

## 3. 关键交互验收点

1. 列表页分页可切换，URL 会保留 `?page=` 参数。
2. 切换分页后自动滚动到页面顶部。
3. 列表页加载失败时展示“重试”按钮。
4. 详情页加载失败时展示“重试”按钮。
5. 文章详情页标题会动态更新为 `文章标题 | MySunriser`。
6. 首页主按钮和右上角导航在正常态与悬停态均应保持可读。
7. 未登录或普通用户在 `/blog` 看不到“新建文章”按钮。
8. admin 在 `/blog` 能看到“新建文章”按钮，按钮文字与底色保持可读。
9. admin 点击“新建文章”进入 `/admin/posts/new`，填写 slug、标题、正文、状态后可保存并跳转到 `/blog/{slug}`。
10. 新建文章时重复 slug 应展示后端错误，不覆盖原文章。
11. admin 打开 `/blog/:slug` 能看到“编辑”按钮，编辑标题、正文、状态、发布时间后可保存并回到阅读态。
12. 新建/编辑表单点击“取消”不提交变更，分别返回列表页或阅读态。
13. Draft 文章对匿名访客和普通 user 不出现在 `/blog` 列表中，直接访问 slug 显示未找到；admin 可访问并编辑。
14. 编辑文章时可上传图片或附件，上传成功后 Markdown 片段插入正文。
15. Published 文章中的 PUBLIC 图片可匿名查看，AUTHENTICATED 图片未登录时显示“请登录后访问图片”，普通 user 登录后可查看。
16. 文章详情页图片点击后可打开大图查看器，遮罩、关闭按钮和 Esc 均可关闭。
17. 文章编辑态底部有红色“删除文章”按钮，删除前连续二次确认，确认后返回博客列表。
18. `/admin/files` 可上传文件、分页查看文件、单选/全选当前页/清空选择。
19. `/admin/files` 批量删除未引用文件成功；删除已引用文件时保留失败项并显示错误。

## 4. 已知限制

1. `npm run preview` 默认不代理 `/api`，仅用于预览构建产物。
2. 异常“超时”场景依赖网络和后端行为，本地可通过断开后端服务模拟。
3. 文章摘要 `summary` 暂未纳入新建/编辑表单。
4. 文件分享直链尚未实现；媒体访问仍遵循文章发布状态和媒体访问级别。
